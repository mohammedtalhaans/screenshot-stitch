# Design direction — Screenshot Stitch 1.2

Audience: people combining conversations, receipts and long pages before sharing. The one job: turn overlapping screenshots into a readable, deliberately edited image.

Palette: workspace #F3F5F7, paper #FFFFFF, ink #182B38, secondary #526775, cobalt #3659D9, quiet green #176959. Warnings use amber only where attention is needed.

Type: locally hosted Manrope for display and major headings; IBM Plex Sans for interface/body. System monospace only for dimensions and geometry. Body 15–16px, controls 14px, metadata at least 12px.

Signature: aligned screenshot strips, a visible overlap band, and the opaque privacy mask. The landing preview demonstrates the exact job through an interactive comparison. No decorative grain, glows, fictional telemetry, tilted cards or repeated reassurance slogans.

Layout: landing is an invitation to work; upload pairs readable ordered images with short settings; editing fits the viewport with a large image and compact controls; export puts the actual output beside its handoff controls.

Desktop editor:
[ compact header / workflow ]
[ Back / Review details          Export ]
[ actionable scan notice                ]
[ image + tools              | inspector ]
[ scrollable image           | details   ]

Mobile editor:
[ brand / workflow ]
[ Review / Export ]
[ image and compact toolbar ]
[ Details / Style / Position ]
[ bounded control panel ]

Critique: a generic white-and-blue SaaS page would be little better than the original dark/lime shell. Keep color quiet and spend personality in the screenshot comparison and hands-on editing. Remove redundant panels; place labels, uncertainty and next actions where the user acts.

Usability goals: accurate zoom; readable preview of uploaded files; stable numbering of masks; no loss of edits on canceled rebuilds; numeric drafts commit intentionally; keyboard and touch editing; 320px layout; reduced motion; opaque masks and final image review.
